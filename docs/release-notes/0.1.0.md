of Preferences/seed storage is unverified. MET redirect/gzip support and traffic
policy treatment remain provider-terms review items. TLS certificate, hostname
and clock verification remain mandatory. See OS9-SEEDS.md for current managed
seed setup/recovery; final first-run instructions must follow reviewed #120.

## Integrated change preview

## 0.1.0

- Add the bounded shared session activity foundation for upcoming native Activity Log windows (#160), with canonical messages and explicit clock trust. Production event wiring and viewers remain pending.

- Add independent changelog fragments and a deterministic release-section preview,
  preserving existing changelog entries and older PRs during the transition (#77).

- Share one POSIX connection timeout across all resolved addresses, including elapsed lookup time once the blocking resolver returns. Reject late success and fail closed on missing or regressing monotonic clocks. Blocking DNS interruption remains outstanding.
- Pass the earlier attempt/caller deadline into POSIX connect, read and write waits, so a short explicit fetch deadline also bounds a silent socket wait. Restore the caller budget after each attempt; blocking DNS and native OS 9 wait integration remain outstanding.
- Apply the borrowed attempt budget to OS 9 asynchronous DNS open/query waits and abandoned-open cleanup, preserving cancellation precedence and callback storage.
- Refuse stream operations at the exact attempt deadline, and reject a backwards stream-clock step even when it remains above the attempt start.

- Stale data now dims everything: wind, humidity and the weather picture fade along with the temperature and condition, in xweather and the OS 9 window (#49, #62).

- Keep a completed OS 9 DNS answer when closing its resolver fails. Warn about cleanup and retain quarantine so subsequent lookups require a restart.
- Close OS 9 network endpoints before Open Transport during explicit shutdown and process exit.
- Roll back OS 9 transport initialization if exit cleanup cannot be registered.

- Display a rounded duration of 60 minutes as “1 h” in refresh countdowns and forecast ages, keeping the existing nearest-minute rounding below an hour.
- Scale the shared weather artwork to fit small panels, retaining complete sun, cloud and precipitation geometry inside60x60 areas. Existing scenes at least100x100 keep their original geometry.
- Scroll and clip long Location text fields while keeping the caret visible and mouse clicks aligned with the displayed text; fix empty-text and bounded ellipsis handling in the shared X11 text helpers.

- Add a separate optional OS 9 timing probe and exploratory offline analysis for #120/#121. No production entropy or provisioning behavior changes; hardware measurements and entropy credit remain pending.

- Preserve the last attempted weather source's error, detail and exit status when fallback is exhausted, including with `-q`. Later skipped sources no longer hide an attempted failure.

- Last-good forecast cache (saving on by default) for CLI, X11 and Mac OS 9, with validated location/units identity and explicit stale labels. Native OS 9 cache acceptance remains pending.

- Persist MET Norway Last-Modified values and use matching If-Modified-Since requests. Valid 304 responses revalidate the matching forecast; unsolicited or mismatched 304 responses remain errors.
- Save forecasts by default, with a persisted Options setting on OS 9 and X11. Turning saving off removes saved forecasts and disables MET Norway with an explanation; Open-Meteo remains available without persistence.
- Preserve the last attempted provider failure when MET is skipped because forecast saving is off.

- Recognize MET Locationforecast's published light sleet/snow thunder-shower spellings, including day, night and polar-twilight variants, so they display thunderstorms rather than a cloud-cover estimate.

- Reword the OS 9 Open Transport glue comments to cite Apple's public TN1173 and our own hardware observations (#63). Comments only; no behaviour change.

- Refuse atomic settings replacement for read-only files, hard-linked files, dangling symlinks, non-regular files, and files owned by another user. Valid symlinks still update their target.
- Preserve existing settings permission bits when saving under a restrictive umask. Oversized rewrites still fail clearly without changing the file.

- Session editors preserve the original on failed edits; package transfers validate producer and download results; OS 9 delivery stages the copy and publishes success only after it completes (#57, #85).

- Stale data now reads age first ("Showing data from 16 min ago. Update failed: ..."), so a long error can no longer push the age off the line, and the temperature and condition are dimmed whenever the data is cached, old or from a failed update (#49, #62).

- Restrict TLS to TLS 1.2 and six ECDHE ChaCha20-Poly1305/AES-GCM suites. Live production-client handshakes passed all four forecast/geocoding services.
- Exclude environment clock/trust overrides from production; explicitly flagged test builds use separate output paths and cannot be installed, packaged or distributed.

- xweather no longer forces a location dialog on first launch: missing or empty settings show and fetch the default location (Madison, WI), and Location... (Ctrl-L) changes it; invalid settings are reported and never replaced (#198; supersedes the automatic picker from #106).
