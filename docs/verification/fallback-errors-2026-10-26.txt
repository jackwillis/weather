Issue #53 C5: preserve cause when multiple sources fail

Policy: successful fallback wins. Otherwise return the last attempted source's
Status unchanged (kind, static message, detail), preserving its CLI exit status.
Sources skipped for missing contact or an unbuildable request path do not hide
an attempted source's failure. If none was attempted, return the last skip;
empty lists return NoSource. Cancellation stops immediately. This does not
aggregate every failure; earlier causes remain warning-level diagnostics.
No dynamic storage, new parser path or Status layout change is introduced.
