Session configuration editor safety: #57 / audit G1 (ctwm and xinitrc)

ctwm undo previously deleted every line after an unmatched BEGIN marker. Both
editors truncated the original during replacement, and xinitrc undo removed any
line containing maul-weather. The updated standalone scripts:
- Validate exact, balanced owned ctwm blocks, refusing nested/incomplete/modified
  contents before deleting any range. Installation requires both known blocks
  or neither; undo may remove a valid owned block. Similar comments are untouched.
- Match only the exact generated xinitrc launch line, preserving unrelated text.
- Use a private sibling temporary directory, checked snapshot/backup/write and
  same-filesystem rename, with cleanup on errors/signals. Preserve ordinary file
  mode/ownership through cp -p as supported by the platform; no ACL guarantee.
- Refuse symlinked or multiply linked configurations and symlink/nonregular
  backup paths. Do not use the old predictable RC.new path. Refuse missing install
  anchors and concurrent content changes detected before replacement.

Both remain standalone because the documented workflow pushes one script to
maul; no unshipped helper dependency is introduced. New Python tests run on
private temp copies and cover old-open-descriptor contents, inode replacement,
mode/backup retention, idempotence, undo, malformed blocks, exact-match removal,
empty output, failed rename/cleanup, link refusal, missing anchors and an old
RC.new symlink. Nine test groups (with subcases). A POSIX shell smoke driver
covers four scenarios and can run unchanged under NetBSD sh/awk.
